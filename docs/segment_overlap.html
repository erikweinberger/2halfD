Collinear Segment Overlap

Given two segments that lie on the same infinite line, do they actually share any points?

The Math

Step 1: Project onto a shared axis

Both segments are collinear — they lie on the same infinite line. We pick the direction of the first segment as our 1D axis:

dir = normalize(v2 - v1)

This gives us a unit vector along the shared line. Now we can describe any point on this line as a single number (its signed distance from v1 along dir).

Step 2: Convert 2D points to 1D positions

Using the dot product, we project each endpoint onto dir relative to v1:

  • a0 = 0 (v1 is our origin)
  • a1 = dot(v2 - v1, dir) = length of first segment
  • b0 = dot(u1 - v1, dir) = where u1 sits on the axis
  • b1 = dot(u2 - v1, dir) = where u2 sits on the axis

The dot product dot(P - v1, dir) gives the signed distance from v1 to P along the line. This collapses the 2D problem into 1D interval overlap.

Step 3: Normalize intervals

Segments can point in either direction, so ensure a0 ≤ a1 and b0 ≤ b1 by swapping if needed.

Step 4: 1D interval overlap test

Two intervals [a0, a1] and [b0, b1] overlap if and only if:

b0 < a1 AND a0 < b1

Intuition: they do NOT overlap only if one is entirely to the left or right of the other (b1 ≤ a0 or a1 ≤ b0). The overlap condition is the negation of that.

Why dot product works as projection

dot(P - v1, dir) = |P - v1| * cos(angle)

When P is on the same line as dir, the angle is 0 or 180 degrees, so this gives the signed distance along the line. It's like reading the position on a ruler laid along the shared line, with v1 as the zero mark.
